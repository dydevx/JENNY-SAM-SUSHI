# Jenny Sam Sushi

Statische, responsive Restaurant-Website auf Deutsch. Kein Build-Prozess und kein Backend erforderlich.

## Lokal starten

```powershell
python -m http.server 4173
```

Danach `http://127.0.0.1:4173` öffnen.

## Veröffentlichung

Der komplette Ordner kann direkt auf GitHub Pages, Netlify oder Vercel veröffentlicht werden. Die Bestellung und Tischreservierung werden im Browser als WhatsApp-Nachricht vorbereitet.

## Menüquelle
